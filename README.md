# Roadkeep

A browser-based 3D medieval lane-defense RTS built with React, TypeScript, and Three.js.

## Features

- Procedural battlefields with winding roads, rivers, bridges, forests, and mines
- Peon economy with wood and gold gathering, houses, garrisons, and road barricades
- Trainable melee, ranged, runner, ward, and ram units
- Drag selection, contextual right-click orders, patrols, control groups, and rally points
- Persistent adaptive enemy AI
- Full-screen camera controls, animation, projectiles, particles, and procedural combat audio

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Third-party asset credits are included in `public/models/kenney/CREDITS.txt`.
