Roadkeep privacy

Roadkeep is a single-player game with an optional invite-link skirmish. There is no account.

The game stores a nickname and settings in localStorage on this device. That includes the skirmish name, graphics and control preferences, tutorial hints already seen, campaign progress, and the foe's learned behavior. That data stays in the browser. Roadkeep does not upload it to an account server.

A skirmish connects the two browsers directly and exchanges match orders and snapshots. The GitHub Pages host sees the page request, including a room code when someone opens an invite link. The PeerJS signaling broker sees the room connection that introduces the two browsers. A public STUN server helps them find a direct path. Roadkeep does not use a relay.

Roadkeep does not add analytics.
